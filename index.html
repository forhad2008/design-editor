🚀 Publish Your Portfolio Live

Your downloaded portfolio is a complete, 100% self-contained web file. Choose any free hosting option below to make it live in under 2 minutes.

Host free on GitHub Pages

  1. Create a new repository named username.github.io.
  2. Rename your downloaded file to exactly index.html.
  3. Upload index.html directly into the repository root.
  4. Your portfolio goes live instantly at https://username.github.io!
git init git add index.html git commit -m "Deploy Portfolio" git branch -M main git remote add origin https://github.com/username/username.github.io.git git push -u origin main

Drag & Drop on Netlify

  1. Rename your downloaded file to index.html and place it inside an empty folder.
  2. Visit app.netlify.com/drop.
  3. Drag and drop the folder into the browser window.
  4. Netlify deploys your site immediately with a free SSL certificate.

1-Command Deploy with Vercel

  1. Place index.html in a new folder.
  2. Run the command below in your terminal:
npx vercel --prod
